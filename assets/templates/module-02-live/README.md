### Результат эфира

Участник должен уметь ответить:

1. Когда опцион решает задачу лучше акции, а когда нет.
2. Чем право покупателя отличается от обязательства продавца.
3. Почему полученная премия ещё не означает прибыль.
4. Почему теоретическая цена, текущий результат и реальная цена закрытия могут отличаться.

### Тайминг

- 00–08: рамка и диагностика
- 08–30: задача опциона и защитный Put на одном примере
- 30–53: премия продавца, хвостовой риск, терминал
- 53–65: контроль и 3 вопроса

### Учебный пример

100 акций по 100 + Put 90 / премия 3 / множитель 100:

- стоимость защиты: 300
- максимальный убыток на экспирации: 1 300
- точка безубыточности: 103

### Ограничения

- без персональных сигналов по позициям участников;
- без детальных Greeks и сложных конструкций;
- без обещания «фиксированного дохода» и безубыточности через ролирование;
- цифры кейсов Кордье/Коровина не озвучивать без отдельной проверки.

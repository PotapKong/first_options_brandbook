# Закреп «Полезные материалы»

**Статус:** `ready-for-user-approval`.

Это отдельный обновляемый каталог ссылок на самостоятельные полезные посты курса. Он не заменяет и не смешивает:

- закреп «Записи эфиров»;
- ежедневный пост «Важное за день»;
- сам пост «Полезные ссылки».

## Состав

- `post.md` — черновик закрепа-каталога;
- `moderation-playbook.md` — правила, по которым в него добавляют новый опубликованный материал.

## Порядок первой публикации

1. Опубликовать отдельный пост «Полезные ссылки: Введение и модули 1–2» с обложкой.
2. Получить его Telegram-permalink.
3. Создать этот закреп и добавить первую строку с permalink на пост «Полезные ссылки».
4. Оставить существующий закреп с записями эфиров отдельным.

## Проверка

- В закрепе только ссылки на наши самостоятельные полезные посты.
- Ссылка на «Полезные ссылки» открывается и ведёт к сообщению с обложкой.
- Нет ежедневных сводок, обычных обсуждений и непроверенной учебной механики.

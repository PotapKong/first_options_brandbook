# Второй закреп: «Важное для потока»

**Статус:** `ready-for-user-approval`.

Пакет отвечает на задачу отделить обязательную навигацию от общего потока сообщений и уже существующего закрепа с записями эфиров.

## Состав

- `post.md` — черновик первого редактируемого сообщения;
- `moderation-playbook.md` — критерии отбора, ритм обновления и роли.

## Граница задачи

Пакет не опубликован. Перед публикацией нужно заменить три плейсхолдера на текущие Telegram-permalink’и и подтвердить создание второго закрепа в учебном чате.

## Проверка после публикации

1. Оба закреплённых сообщения видны в шапке чата.
2. Ссылка на модуль, индекс записей и хэштег `#эфир` открываются корректно.
3. В новом закрепе нет непроверенных формул, персональных рекомендаций и устаревших действий.
4. Студент может за 30 секунд найти текущий модуль, запись и следующий шаг.

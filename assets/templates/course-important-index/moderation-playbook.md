# «Важное для потока»: правила обновления

## Назначение

Один редактируемый индекс для студента, который не читает весь чат. Он отвечает на два вопроса: «Что изменилось сегодня?» и «Где лежит большой материал, который нельзя потерять?»

Это не новый ежедневный пост, не чат-новости и не второй архив записей. Отдельный подробный материал публикуется своим постом; индекс хранит короткое объяснение и permalink на него.

## Что добавлять

Добавлять можно только запись с ясным действием для ученика:

1. модуль открыт или изменён;
2. обязательный тест, задание, дедлайн или эфир;
3. новая запись эфира;
4. проверенный учебный разбор с понятной темой;
5. критичное организационное изменение доступа или расписания.

Формат одной записи:

```text
**Название**
Зачем открыть / что сделать одним предложением.
[Ссылка на сообщение или урок]
```

## Что не добавлять

- обсуждения участников и рабочие гипотезы;
- расчёты без экспертского review;
- одиночные ответы в комментариях;
- ссылки без объяснения, зачем они нужны;
- объявления, которые уже не требуют действия.

## Ритм

- Создать один второй закреп рядом с индексом записей эфиров.
- У индекса три слоя: `Сегодня` → `Сейчас по курсу` → `Большие материалы и записи`.
- В `Сегодня` держать не больше трёх пунктов. На следующий день убрать утратившее срочность или перенести в постоянный слой, если материал остаётся полезным.
- Новое подробное объяснение сначала публиковать отдельным сообщением, затем добавить в индекс одну строку с permalink. Не вклеивать длинный текст внутрь закрепа.
- Не выпускать новый пост ради каждой мелочи и не добавлять в индекс обычные ответы из ветки.
- После изменения проверять каждый permalink из Telegram-клиента.

## Роли и проверка

| Тип записи | Кто подтверждает содержание | Кто обновляет индекс |
|---|---|---|
| Модуль, тест, программа | куратор/автор курса | Михаил или назначенный редактор |
| Эфир и запись | ведущий/куратор | редактор после публикации записи |
| Опционная механика, формула, P/L | Сэм или Михалыч | редактор только после review |
| Организационное изменение | владелец процесса | редактор |

## Текущая первая версия

В первую публикацию входят только:

- ссылка на открытый модуль 2;
- ссылка на существующий индекс записей эфиров;
- инструкция ставить `#эфир` для вопросов к эфиру.

Альбом P&L Call/Put и подборка конструкций в эту версию не входят: первый ещё на экспертском review, второй не предоставлен.

# Первый опционный — Brandbook

Публичный репозиторий дизайн-системы образовательного проекта «Первый опционный».

Проект объединяет две практические команды и объясняет опционы через сценарии, заранее определённый риск и управление позицией — без сигналов, хайпа и обещаний доходности.

## Основа айдентики

**Dual Delta** — две переплетённые сине-зелёные ленты. Центральное negative space формирует `1` и strike. Синий и зелёный представляют равноправных партнёров.

## Структура

```text
brandbook/
  v1/                  текущий выпущенный PDF и токены
  v2/                  следующая сборка брендбука
assets/
  logo/                утверждённые мастер-файлы знака
  mascots/
    delta/             концепты и утверждённые версии Delta
    strike/            концепты и утверждённые версии Strike
  ribbons/             фирменные ленточные объекты
  scenes/              совместные сцены и сюжетные композиции
  patterns/            фоновые паттерны
  templates/           прикладные шаблоны
prompts/               production-промпты GPT Image 2
reviews/               QA и экспертные оценки
references/            входные материалы
```

## Правило добавления актива

Каждый новый визуальный элемент проходит маршрут:

1. бриф и семантика;
2. генерация в GPT Image 2;
3. визуальный QA;
4. проверка в реальном размере;
5. экспертный review;
6. статус `approved` или `rejected`;
7. только `approved` попадает в брендбук v2.

## Ограничения

Не использовать крипто-/gaming-эстетику, казино, ракеты, золото, быков/медведей, фейковые терминалы и неподтверждённые рыночные данные. Текущие AI-рендеры являются production raster, а не юридически очищенными векторными товарными знаками.

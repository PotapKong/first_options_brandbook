# Первая карта российского опционного рынка — дизайн-макет v1

20-страничный A4 PDF для проекта «Опционы с Нуля с Михалычем и Сэмом Шариповым».

## Состав

- `Первая_карта_российского_опционного_рынка_MO_обновлено.md` — принятый исходный текст;
- `Первая_карта_российского_опционного_рынка_дизайн-макет.html` — самодостаточный HTML с встроенными шрифтами и изображениями;
- `Первая_карта_российского_опционного_рынка_дизайн-макет.pdf` — основной макет с 13 видимыми дизайнерскими комментариями;
- `build_pdf.py` — сборка HTML и PDF;
- `qa_pdf.py` — структурная проверка и рендер контакт-листа;
- `qa-contact-sheet.jpg` — постраничный лист для визуального QA;
- `fonts/` — Manrope и JetBrains Mono, используемые в макете.

## Сборка

```bash
python build_pdf.py
python qa_pdf.py
```

Нужны Python-пакеты `markdown`, `beautifulsoup4`, `weasyprint`, `pypdf`, `PyMuPDF` и `Pillow`.

## Статус

`design-mockup-v1`: служебные оранжевые комментарии оставлены видимыми. Перед ученической публикацией рыночные данные нужно обновить, комментарии реализовать и убрать отдельной финальной сборкой.
